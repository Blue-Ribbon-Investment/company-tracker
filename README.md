# Company Tracker — daily detailed scan of a watchlist of companies

Every morning (two tries, ~05:15 and ~06:05 IST) this repo runs on GitHub whether or not a laptop is on:

1. **fetch** — `fetch_directory.py` refreshes the search box's company directory (NSE + NSE SME, name + code), and `fetch_companies.py` pre-fetches for every company in `watchlist.json`: corporate filings (NSE announcements), bulk/block deals, Google-News headlines for the company, its competitors and its industry, and StockTwits chatter. All of it lands in `runs/DATE/raw/<SYM>.json`.
2. **Quiet-day shortcut** — a company with no filings and no fresh news gets an automatic one-line "quiet" block (generated by plain code, no AI cost). `triage.json` lists the companies that DO have signal, grouped up to 5 per digest file.
3. **synth** — Claude (via `claude-code-action`, the same OAuth token as the markets brief) writes `runs/DATE/digests/digest_i.html` for each group, following `example_digests.html`.
4. **publish** — `build_companies_site.py` merges digests + quiet blocks into one `content.html`; `build_site.py` builds the website page (search + Track + add-a-company box, using `directory.json` and `watchlist.json`) and the email; the page deploys to GitHub Pages; `send_email.py` emails it (Gmail app password, same secrets as the markets brief).

## What the reader sees

One public page per day, same look as the markets brief:
- **Search box** filters that day's company cards.
- **Track** on each card pins the company to the top (stored in the reader's browser).
- **Add a company** searches the full listed-stock directory; **Save list** copies the tracked list ("CODE, Name" lines) to send back to add companies for the next day.

## Editing the watchlist (the one manual step)

`watchlist.json` is the source of truth. One entry per company:

```json
{"symbol": "KMEW", "name": "Knowledge Marine", "market": "IN", "exchange": "NSE",
 "industry": "Marine / shipbuilding",
 "competitors": [{"s": "COCHINSHIP", "n": "Cochin Shipyard"}]}
```

- `market` is `IN` (NSE/NSE-SME symbols; filings + NSE bulk/block deals) or `US` (add `"cik"` — the 10-digit SEC CIK, no leading zeros needed).
- `competitors` need only the exchange `s` code (and a display `n`).
- Blank `industry`/`competitors` are allowed; Claude's digest just has less to say about those.

**One-click save flow:** the reader clicks **Save list** on the page → gets lines like `KMEW, Knowledge Marine` → they land here as new `watchlist.json` entries (add market IN + blank industry/competitors), commit, push. The next morning's run picks them up. `import_watchlist.py` does the same from a text file or a screener.in CSV export.

## Running locally (test only; NSE is blocked off-laptop, everything else works)

```
python -I -X utf8 fetch_directory.py runs/DATE      # empty on a laptop; real on GitHub
python -I -X utf8 fetch_companies.py runs/DATE
# write runs/DATE/digests/digest_0.html ... (the AI step), then:
python -I -X utf8 build_companies_site.py runs/DATE "Sunday 8 November 2026"
python -I -X utf8 build_site.py runs/DATE/content.html site out "Sunday 8 November 2026" "11:00 AM" https://blue-ribbon-investment.github.io/company-tracker/ runs/DATE/directory.json watchlist.json
```

## Secrets (GitHub → Settings → Secrets and variables → Actions)

`ANTHROPIC_API_KEY` (the AI step — a plain Anthropic API key; bills to that key's usage, not to the Claude desktop OAuth login the markets brief uses) plus `GMAIL_USER`, `GMAIL_APP_PASSWORD`, `EMAIL_TO` (the email step, same values as the markets brief).

## Known limits

- NSE filing feeds only open from GitHub's servers (laptop runs get 0 filings; the page says so in a source note).
- StockTwits is a noisy sentiment breadcrumb, not a clean news feed. X/Twitter is not scanned (no reliable unattended free access) — the digest notes this.
- The "add a company" choice is saved on the reader's device; it only reaches the next report after `watchlist.json` is updated (one-click save flow).
